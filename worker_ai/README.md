# AI-ассистент по отзывам: worker_ai

Фоновый сервис, который отвечает на отзывы. С базой сайта он напрямую не работает, все идет через HTTP API, поэтому его можно запускать отдельно, на другом сервере или в своем контейнере.

## Что делает сервис

- Раз в `WORKER_POLL_INTERVAL` секунд (по умолчанию 10) забирает с сайта отзывы со статусом `new`.
- Определяет тон отзыва и пишет ответ через OpenAI. Если ключа нет или запрос упал, тон определяется по словам-маркерам, а ответ берется из заготовок.
- Добавляет ответ отдельным комментарием под отзывом и помечает обработанными и отзыв, и ответ.
- Шлет уведомление о новом отзыве в Telegram.
- На собственные ответы не реагирует, так что цепочки автоответов не возникает.

## Файлы

- `config.py`: настройки из `.env`.
- `client.py`: HTTP-клиент для API сайта.
- `models.py`: модели данных.
- `processor.py`: запрос к OpenAI и запасная логика.
- `state.py`: локальная память о том, что уже обработано и о чем уже пришло уведомление.
- `telegram_bot.py`: уведомления в Telegram.
- `worker.py`: основной цикл.
- `Dockerfile`, `docker-compose.yml`: запуск в контейнере.

## Настройки

Скопируйте `.env.example` в `.env`:

```env
TARGET_SITE_URL=http://127.0.0.1:8000
WORKER_API_TOKEN=change-me
WORKER_POLL_INTERVAL=10
STATE_FILE_PATH=data/state.json
OPENAI_API_KEY=
OPENAI_MODEL=gpt-4.1-mini
AI_AUTHOR_NAME=AI Support
TELEGRAM_BOT_TOKEN=
TELEGRAM_USER_CHAT_ID=
```

`WORKER_API_TOKEN` должен совпадать со значением в `site/server/.env`, иначе сайт не даст сервису обновлять отзывы. Если у сервера нет доменного имени, в `TARGET_SITE_URL` можно указать IP, например `http://192.168.1.20:8000`.

## Запуск

В контейнере, из папки `worker_ai`:

```bash
docker compose up --build
```

Без контейнера:

```bash
pip install -r requirements.txt
python worker.py
```

## Уведомления в Telegram

1. Создайте бота через `@BotFather` и возьмите `TELEGRAM_BOT_TOKEN`.
2. Откройте личный чат с ботом и нажмите `/start`, иначе бот не сможет вам писать.
3. Узнайте id этого чата и впишите его в `TELEGRAM_USER_CHAT_ID`.

Старый параметр `TELEGRAM_CHAT_ID` тоже работает, но для личных уведомлений лучше `TELEGRAM_USER_CHAT_ID`. Если Telegram не настроен, сервис продолжит отвечать на отзывы, просто без уведомлений.
